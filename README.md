# Stay Dead / Better Phone UI compatibility proposal

Unofficial compatibility proposal for:
- Stay Dead 0.1.2 (NightCityNemesis)
- Better Phone UI 1.1.1

## Problem
Better Phone UI displays journal placeholder text instead of
Stay Dead's dynamically generated messages.

## Proposed changes
Retrieve dynamic message bodies and contact names through
the NightCityNemesis.NcnPhone API, keeping the journal fallback.

The diff is provided for review by both mod authors.
This is not a ready-to-install mod.

## Validation
Joint REDscript compilation passed.
In-game behavior has not yet been verified.
Compilation without Stay Dead has not been separately tested.
